# 花生十三

**花生十三**（huashengshisan.cn）是一个面向考公与考研学习者的静态资源索引站点，将分散在腾讯文档中的课程目录、笔记群与更新日志集中在一页之内，帮助用户一键直达所需内容。

## 主要功能

- **考公课程目录**：覆盖公务员、国考省考、教师、事业、文职、三支、社工、英语、财会、司法等公职类考试课程索引。
- **考研课程目录**：覆盖英语、数学、政治、管理类联考、专业课、笔试、冲刺、押题、复试等研究生入学考试全阶段课程索引。
- **免费笔记网盘群**：进入笔记网盘共享群入口，获取资料共享与学习交流通道。
- **课程更新日志**：查看课程上新与内容修订的时间线记录。
- **联系 QQ 一键复制**：薄荷绿联系区提供考公 QQ（1620668378）与考研 QQ（1024687680），点击整张卡片即复制并提示"QQ 已复制"。
- **今日日期展示**：顶部导航栏右侧实时显示当天日期与星期（窄屏自动省略星期）。
- **返回顶部**：右下角悬浮按钮，滚动一屏后出现，点击回到页首。
- **响应式布局**：自适应手机、平板、PC，不同设备浏览自动缩放；移动端导航折叠为汉堡菜单。

## 视觉设计

第二版采用 **Soft Brutalism（轻量新粗野）** 风格，替换掉初版的宣纸仿古配色：

- **配色**：暖米白底 + 荧光柠檬黄主色，辅以薄荷绿／天蓝／薰衣草紫区分四个入口，珊瑚红作点缀；通篇浅色，无大面积深色区块。
- **字形**：超粗无衬线中文标题，字距收紧；数字与标签使用等宽字体，强化"索引／票据"感。
- **视觉锤**：右侧一张倾斜的 13 号入场券（打孔虚线、条形码、FREE 贴纸），把品牌数字变成可识别的图形符号。
- **版面**：不对称 Bento 网格（7:5 / 5:7）取代规整的 2×2 卡片；硬描边 + 实心投影、悬停位移制造节奏。页面不含跑马灯。
- **收尾**：已移除独立页尾区，页面在薄荷绿联系区（QQ 卡片）结束，不再显示品牌大标题、域名按钮、快速链接、描边水印与版权条。域名 `huashengshisan.cn` 以纯文本形式展示在联系区标题「联系」之后，不带链接、不可点击。
- **动效**：默认开启克制的悬停与滚动入场动效，并遵循 `prefers-reduced-motion` 系统设置自动关闭；无循环滚动动画。

## 部署

单文件 `index.html`，零外部依赖（字体、图标、纹理均为系统字体与内联 SVG／CSS），直接上传或用 Git 推送至 Cloudflare Pages 即可，无需构建步骤。
