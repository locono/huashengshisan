# 花生十三

**花生十三**（huashengshisan.cn）是一个面向考公与考研学习者的静态资源索引站点，将分散在腾讯文档中的课程目录、笔记群与更新日志集中在一页之内，帮助用户一键直达所需内容。

## 主要功能

- **考公课程目录**：覆盖公务员、国考省考、教师、事业、文职、三支、社工、英语、财会、司法等公职类考试课程索引。
- **考研课程目录**：覆盖英语、数学、政治、管理类联考、专业课、笔试、冲刺、押题、复试等研究生入学考试全阶段课程索引。
- **免费笔记网盘群**：进入笔记网盘共享群入口，获取资料共享与学习交流通道。
- **课程更新日志**：查看课程上新与内容修订的时间线记录。
- **联系 QQ 一键复制**：页尾提供考公 QQ（1620668378）与考研 QQ（1024687680），点击号码即复制并提示"QQ 已复制"。
- **今日日期展示**：顶部导航栏右侧实时显示当天日期与星期。
- **返回顶部**：右下角悬浮按钮，滚动一屏后出现，点击回到页首。
- **响应式布局**：自适应手机、平板、PC，不同设备浏览自动缩放；移动端导航折叠为汉堡菜单。
